# 武器（P2-01）

定义、注册表、背包在 `src/core/weapon.*`；战斗执行在 `core/combat.*`（`WeaponManager`）。行为由 `AttackKind` 枚举决定（Projectile / Burst / Zone），不按武器 ID 分支，新增武器只需新增 `WeaponDefinition`。

| ID | 类型 | 行为 |
|----|------|------|
| bubble_shot | Projectile | 自动射向最近敌人。基础 12 伤害 / 0.8s / 射程 520；投射物数量、穿透、击退均按定义执行（默认 1/0/0）。 |
| tail_sweep 摆尾波 | Burst | 以玩家为中心半径 110 的一次震荡，范围内每个存活敌人每次触发只受一次伤害，击退 40（限制在场地内）。范围内无敌人时不触发、不消耗冷却。显示 0.25s 圆环。 |
| data_pool 数据涟漪 | Zone | 在施放范围 420 内最近敌人处生成半径 90、持续 3s 的区域；在 0.5、1.0 … 3.0s 各结算一次（共 6 次），之后移除。无目标或区域已满（32）时不生成、不消耗冷却。 |

## 规则
- 初始只有角色的初始武器（鱼：bubble_shot）；其余通过升级卡获得。背包最多 6 个互不相同的武器，每个都攻击，各自独立冷却，新获得的武器立即可用。
- 升级/属性变化原地更新：保留各武器冷却比例，不重置敌人、RNG、HP。伤害 = 定义基础值 × (1 + 每级加成 × (等级-1))，玩家伤害倍率与暴击在出手时应用一次。
- 暴击：每次攻击（每颗投射物、每次震荡、每个区域）抽取一次 RNG；区域的单次伤害在生成时固定。
- 所有伤害走 `CombatWorld::damage_enemy`：已死亡敌人不再受击，击杀与 XP 事件只记一次。顺序：震荡、投射物、区域 tick。
- 穿透：每颗投射物记录已命中的敌人 ID（最多 pierce+1 个），不会重复命中同一敌人。
- 上限：6 武器 / 512 投射物 / 256 敌人 / 32 区域 / 64 个瞬时视觉。
- 仅 Playing 状态推进冷却、区域与视觉；暂停、升级选择和终局均冻结。
- 裸 `CombatWorld`（`CombatConfig` 覆盖）仍是单个由配置驱动的泡泡武器；`set_loadout` / `initialize_run_loadout` 安装真实装备。无效装备（空、超过 6、重复 ID、数值越界）整体拒绝。
