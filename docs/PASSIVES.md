# 角色被动

默认角色被动由用户指定为“吃白饭”，ID `free_rice`。拾取经验物体获得的实际经验（已计入经验倍率）每累计100点，回复当前最大生命值的3%。经验不被花掉，余量继续累计；一帧跨越多个阈值按次数累计，回复最多填满血条。满血触发也消耗本次回复，不保存治疗。直接工具经验奖励不算拾取。

`PassiveRegistry` 注册不可变配置，`PassiveRuntime` 由每局 `ProgressionSession` 独立持有；另有显式无效果的 `none`。未知配置ID拒绝开始游戏。纯C++实现无Godot依赖。共享 `advance_run` 在战斗伤害、计时后收集经验并应用回复，然后才打开升级面板。死亡帧不能被同帧经验救活；暂停、升级和终局不处理拾取/回复。重开创建新会话，进度归零。

阈值使用常数时间计算；极端输入受界限约束，触发计数饱和，治疗比例独立累计，不能因显示计数溢出丢失小比例配置的治疗。真实治疗量由 `CombatWorld::heal` 限制为有限正数、活着且Playing、最多最大生命值。界面只读运行时状态，不执行被动逻辑。
